# Runtime Evidence

This directory stores raw `sqlcmd` output generated by corrected Step 13 executions.

Evidence files must identify the scenario and session, for example `P1-session-a.txt`, `P1-session-b.txt`, and `P1-invariants.txt`. Expected-result documentation is not runtime evidence.

Each `*-setup.txt` file includes database isolation options and baseline-contract verification. Each retained two-session worker output records its own final `@@TRANCOUNT`. `cleanup-final-count.txt` records the server-wide post-cleanup count.
