# 1. Business Purpose
    Describe:
    - What problem the organization is trying to solve.
    - Why the database system is needed.
    - Main objectives of the system.

# 2. Actors
    Identify all actors.
    For each actor provide:
    - Actor Name
    - Description
    - Responsibilities

# 3. Entities
    Identify all candidate entities.
    For each entity provide:
    - Entity Name
    - Description
    - Justification from requirements

# 4. Attributes
    For each entity identify:
    - Primary attributes
    - Descriptive attributes
    - Candidate identifiers
    Present results in table form.

# 5. Relationships
    Identify relationships between entities.
    For each relationship provide:
    - Relationship Name
    - Participating Entities
    - Business Meaning

# 6. Cardinalities
    For every relationship identify:
    - Relationship
    - Cardinality
    - Participation Constraints
    - Justification

# 7. Business Rules
    List all explicit business rules.
    Do not invent rules.
    For each rule provide:
        - Rule Description
        - Requirement Evidence

# 8. Assumptions
    List assumptions that are not explicitly stated in the requirements.
    For each assumption provide:
        - Assumption Description
        - Justification

# 9. Open Questions
    List unclear or ambiguous requirements.
    For each question provide:
        - Question
        - Working Assumption

## Self-Review Checklist
Before finalizing:
- Every actor appears in at least one relationship.
- Every entity has at least one attribute.
- Every relationship has cardinality.
- Every business rule is supported by the requirement.
- Assumptions are separated from requirements.
